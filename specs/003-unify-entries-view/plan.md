# Implementation Plan: Unified Entries View

**Branch**: `003-unify-entries-view` | **Date**: 2026-04-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/003-unify-entries-view/spec.md`

## Summary

Replace the two-tab Entradas view (Transacciones / Recurrentes) with a single chronological list showing all entries. Entries generated by an active recurring template display a recurrence badge. Deleting a recurring entry cancels the template (soft-delete) with a differentiated confirmation dialog; deleting a one-off entry permanently removes it. The change is UI-layer and provider-layer only — no schema migrations, no new tables.

## Technical Context

**Language/Version**: Dart (Flutter stable channel)
**Primary Dependencies**: flutter_riverpod, go_router, drift, shared_ui, shared_models, shared_services
**Storage**: Drift (SQLite), local on-device only
**Testing**: flutter_test, Riverpod test utilities
**Target Platform**: Desktop (primary), Android (planned)
**Project Type**: Desktop app (Flutter)
**Performance Goals**: Instant list rendering for personal-scale data (< 10k entries)
**Constraints**: Offline-only, no network calls, no sensitive data in logs
**Scale/Scope**: Single user, personal finance, ~5 screens
